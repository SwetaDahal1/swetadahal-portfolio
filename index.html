How I test

A simple routine that catches problems early and keeps developers unblocked.

  1. UnderstandRead the requirement, ask questions, and learn what the user needs.
  2. DesignWrite test cases for normal use, edge cases and error paths.
  3. ExecuteTest across browsers and screen sizes, including the API when needed.
  4. Report and retestLog clear bugs, verify the fix, and run regression checks.

What a good bug report includes

  • Clear title
  • Steps to reproduce
  • Expected result
  • Actual result
  • Severity and priority
  • Browser, device and build
  • Screenshot or video
  • Console or network logs
